**结论：本地选择器、策略接口、统计内核及回归测试通过；不是远端运行或正式实验验收。** 没有提交或推送本次改动，没有连接远端、加载真实实验 checkpoint、启动 GPU smoke、执行正式轨迹或重新训练。本次统计测试只使用测试样例，不是新实验结果。

## 1. 已实现的范围

| 部分 | 已完成内容 |
|---|---|
| 实验协议 | UK48−U 为唯一主比较；UN48 为辅助对照；冻结容量、因果边界、seeds、失败处理和后续验收条件。 |
| UK48 / UN48 选择器 | 从原始 U32 索引追加缺失边界，或追加同一历史下等量随机非边界帧；完整保留 U，不重复、不借用未来。 |
| 容量和空位 | 固定48帧／768 token槽；不补额外有效帧。取特征后、归一化前的空位补零，attention mask 为 false。 |
| 独立策略接口 | 新实验需要显式配置；未配置时拒绝推理，不能静默变为 Uniform48；重置清除上一个 episode 的历史、上下文和失败状态。 |
| 加载接口 | 仅显式 opt-in 启用扩容；复制原配置、只改 memory budget；新组要求严格权重加载，不修改 checkpoint 元数据或旧默认行为。 |
| 运行契约 | 固定16 tasks、test episodes 0–49、两个新组共1,600条正式轨迹；生成独立 selector seed 表和只读准备状态。 |
| 日志验证 | 验证选帧、因果前缀、随机数、有效／padding 数量、张量规格和连续调用；与真实 MemoryBuffer 的 CPU 测试衔接。 |
| 统计内核 | 正式入口要求800条 U、800条 UK48、800条 UN48 完整配对；拒绝缺失／重复／不合规记录；主比较与辅助比较分开。 |

注意：后续归一化或编码器偏置可以让被屏蔽位置的数值不再为零；这不等于添加了有效记忆。不得为此修改原编码器。实际768槽的完整模型推理仍需 GPU 验证。

- 既有 `results/keyframe_neighborhood_sampling/` 未纳入本次修改、清理或统计。
- 真实模型配置的 CPU 输入规格检查接受768槽；加载流程的严格检查由测试替身验证。它们不证明真实权重能够完成768槽 GPU 推理。

- 统计入口校验 U 及所有结果的摘要绑定，不会凭一个 `PASS` 标记认可基线，也不能替代对外部原始初始状态、图像与运行环境的审核。
